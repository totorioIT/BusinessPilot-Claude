# Sprecher-Skript (30 Sekunden)

Tempo: zügig, ca. 2,5 Wörter pro Sekunde. **Fett** = betonen. / = kurze Pause.

| Zeit | Im Bild | Sprechen |
|---|---|---|
| 0:00–0:03 | Hook-Text | Du klickst. / **Achtzig Millisekunden.** / Was passiert da eigentlich? |
| 0:03–0:07 | Laptop → Router | Zuerst schickt dein Laptop die Anfrage an den **Router**. |
| 0:07–0:11 | DNS | Aber Computer können keine Namen. / **DNS** macht daraus eine IP-Adresse. |
| 0:11–0:15 | TCP-Handshake | Dann Händeschütteln mit dem Server. / **SYN. / SYN-ACK. / ACK.** |
| 0:15–0:19 | HTTP | Jetzt fordert HTTP die Seite an. / Antwort: **zweihundert, OK.** |
| 0:19–0:21 | Seite geladen | Fertig. / In unter **hundert** Millisekunden. |
| 0:21–0:24 | Hotel-WLAN | Und warum will **Hotel-WLAN** erst ein Login? |
| 0:24–0:26 | Router blockt | Weil der Router deine Anfragen **abfängt**. |
| 0:26–0:28 | Freigeschaltet | Login rein – / und du bist **durch**. |
| 0:28–0:30 | Outro | Folg mir. / Teil zwei: **VPN.** |

Aussprache: SYN = „Sinn“, ACK = „Äck“, DNS = „De-En-Es“, HTTP = „Ha-Te-Te-Pe“.

## Am Stück
Du klickst. Achtzig Millisekunden. Was passiert da eigentlich?
Zuerst schickt dein Laptop die Anfrage an den Router.
Aber Computer können keine Namen. DNS macht daraus eine IP-Adresse.
Dann Händeschütteln mit dem Server. SYN. SYN-ACK. ACK.
Jetzt fordert HTTP die Seite an. Antwort: zweihundert, OK.
Fertig. In unter hundert Millisekunden.
Und warum will Hotel-WLAN erst ein Login?
Weil der Router deine Anfragen abfängt.
Login rein – und du bist durch.
Folg mir. Teil zwei: VPN.
